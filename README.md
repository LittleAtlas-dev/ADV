# ADV — Pinterest RSS

GitHub Actions → Gemini → Higgsfield → JPEG 1000×1500 → репозиторий сайта → RSS → Pinterest.

Активен только Pinterest: ежедневно 07:40 UTC или ручной запуск. Остальные скрипты закомментированы, workflows сохранены как .yml.disabled. Dockerfile и Render Blueprint закомментированы: n8n не требуется.

Настройка: [RSS_SETUP_RU.md](RSS_SETUP_RU.md).

Контент посвящён Little Atlas: сильные стороны ребёнка, бережное родительство, персональные мандалы, семейные памятные карточки и Free Atlas. Язык пинов — английский. Это символический и художественный продукт: контент не обещает диагностику или достоверное предсказание будущего.

SITE_URL укажите для подтверждённого сайта Little Atlas (например https://little-atlas.com). LANDING_REPO должен указывать на репозиторий, который действительно публикует RSS на этом домене. Сайт и настройки Pinterest этим коммитом не меняются.
